# STAND FARM: Hokkaido

Game farming-adventure 2D pixel art dengan latar desa fiksi Yukimori di Hokkaido, Jepang.

## Build saat ini
**v0.2 — GitHub Development Build**

### Fitur
- Pilih karakter laki-laki/perempuan.
- Gerakan empat arah dengan tombol sentuh atau keyboard.
- Kamera mengikuti karakter.
- Desa demo dengan sungai, jembatan, rumah, ladang, pohon, dan NPC Mira.
- Interaksi dasar dengan rumah dan NPC.
- Pergantian hari dan pemulihan stamina.
- Penyimpanan lokal melalui browser (`localStorage`).

### Cara menjalankan
1. Unduh repository atau buka `index.html` melalui browser.
2. Untuk pengujian yang lebih konsisten, jalankan melalui GitHub Pages.
3. Di Android, gunakan Chrome dan kontrol layar.
